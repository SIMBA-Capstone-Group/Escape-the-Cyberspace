# Escape-the-Cyberspace
A cybersecurity-centered game that explores concepts such as networking, digital forensics, cryptography, and more. This game is has several levels mimicking reall-life escape rooms that follows a storyline to investigate Dr. G and escape the mansion.

## DEVELOPER INFO
### Branches
When naming a branch, please use the following syntax:
```
<sprint_number>.<iteration>_<object>

EX: 3.1_FilingCabinet
```
When testing a branch for merge, pull a new branch from main, and name it:
```
TEST_<object>_<iteration>

EX: TEST_FilingCabinet_1
```
